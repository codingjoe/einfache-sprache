**Ihr Blutdruckmittel**

**Wie Sie das Mittel nehmen**

Nehmen Sie das Mittel einmal am Tag. Am besten morgens. Nehmen Sie es jeden Tag zur gleichen Zeit.

**Wenn Ihnen schwindelig wird**

Ihr Blutdruck kann zu niedrig werden. Dann wird Ihnen schwindelig. Setzen Sie sich dann hin. Bleiben Sie kurz sitzen. Stehen Sie erst dann langsam auf. So vermeiden Sie einen Sturz.

**Setzen Sie das Mittel nicht allein ab**

Nehmen Sie das Mittel weiter. Wenn Sie es absetzen, kann Ihr Blutdruck wieder steigen. Das ist gefährlich. Sprechen Sie vorher mit uns.

**Wann Sie uns anrufen sollen**

Schwellen Ihre Beine an? Dann rufen Sie in der Praxis an. Eine Schwellung kann eine Nebenwirkung sein. Wir prüfen das dann.

**Sie haben Fragen?**

Rufen Sie uns an. Wir erklären Ihnen alles in Ruhe.
